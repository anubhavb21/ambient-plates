# Ambient Plates

An ambient clock for a TV screen with five themes: Editorial (nature photos and painted scenes), Anime Sky, Comic Strike, Cyber District and Cosmic Saga. All art in the four animated themes is drawn in code and is original.

## Remote / keyboard

- 1 to 5: pick a theme (1 Editorial, 2 Anime Sky, 3 Comic Strike, 4 Cyber District, 5 Cosmic Saga)
- 0: back to automatic (the theme follows the time of day)
- Left / Right: previous / next theme
- OK / Enter, or a click: the theme's effect
- 9: performance readout
